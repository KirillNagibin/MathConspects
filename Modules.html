Модуль числа: Полное руководство

Почему «отбросить минус» больше не работает?
В младших классах модуль объясняют просто: $|-5| = 5$. Но в старшей школе под модулем стоят переменные: $|x-3|$. Мы заранее не знаем знак выражения внутри, поэтому просто убрать скобки модуля нельзя — необходимо применять строгие математические определения.

1. Два определения модуля: Алгебра и Геометрия

Для решения задач необходимо свободно переключаться между алгебраической записью и геометрической интерпретацией модуля.

1. Алгебраическое определение
$$|x| = \begin{cases} x, & \quad x \ge 0 \\ -x, & \quad x < 0 \end{cases}$$ Если подмодульное выражение неотрицательно ($x \ge 0$), модуль раскрывается без изменения знака.
Если выражение отрицательно ($x < 0$), перед ним ставится знак «минус» для компенсации знака: $-(-5) = 5$.
2. Геометрический смысл
$$|x - a| = \rho(x; a)$$ Модуль разности двух чисел равен расстоянию между этими точками на числовой прямой.
Уравнение $|x - 3| = 5$ означает поиск всех точек $x$, удаленных от точки $3$ ровно на $5$ единиц (это точки $-2$ и $8$).

2. Базовые свойства и Связь с корнями

Основные алгебраические тождества, используемые при преобразовании выражений с модулем:

Мультипликативность
$$|a \cdot b| = |a| \cdot |b|$$ $$\left|\frac{a}{b}\right| = \frac{|a|}{|b|} \quad (b \neq 0)$$
Симметричность
$$|-a| = |a|$$ $$|a - b| = |b - a|$$
Четная степень
$$|a|^2 = a^2$$ Возведение в квадрат позволяет избавиться от знака модуля.
Важнейшее тождество: Корень из квадрата
Запись $\sqrt{x^2} = x$ неверна при отрицательных значениях переменной. Так как результат извлечения арифметического квадратного корня обязан быть неотрицательным, действует строгое правило:
$\sqrt{x^2} = |x|$

3. Схемы равносильных переходов

Вместо раскрытия модуля по определению через рассмотрение знаков на промежутках, большинство стандартных задач решается с помощью равносильных переходов:

Вид Равносильный переход Условия (ОДЗ) Математическая суть
Уравнение
$|f(x)| = a$		 $$\left[\begin{gathered} f(x) = a \\ f(x) = -a \end{gathered}\right.$$ $a \ge 0$
(При $a < 0$ корней нет: $x \in \emptyset$)		 Точки, удаленные от нуля на расстояние $a$. При $a = 0$ оба случая сливаются в одно уравнение $f(x) = 0$.
Уравнение
$|f(x)| = g(x)$		 $$\begin{cases} g(x) \ge 0 \\ \left[\begin{gathered} f(x) = g(x) \\ f(x) = -g(x) \end{gathered}\right. \end{cases}$$ Правая часть обязана быть неотрицательной: $g(x) \ge 0$ Так как левая часть заведомо $\ge 0$, правая часть также не может быть отрицательной. Условие для $f(x)$ писать не требуется.
Уравнение
$|f(x)| = |g(x)|$		 $$\left[\begin{gathered} f(x) = g(x) \\ f(x) = -g(x) \end{gathered}\right.$$ Дополнительных условий нет (только ОДЗ самих функций) Модули двух выражений равны тогда и только тогда, когда сами выражения либо равны, либо противоположны по знаку.
Неравенство
$|f(x)| < g(x)$		 $$\begin{cases} f(x) < g(x) \\ f(x) > -g(x) \end{cases}$$Двойное: $-g(x) < f(x) < g(x)$ Условие $g(x) > 0$ выполняется автоматически Пересечение (система). Расстояние меньше заданного: значения $f(x)$ зажаты внутри интервала $(-g(x); g(x))$.
Неравенство
$|f(x)| > g(x)$		 $$\left[\begin{gathered} f(x) > g(x) \\ f(x) < -g(x) \end{gathered}\right.$$ Выполняется при любых $g(x)$ (при $g(x) < 0$ решение — вся ОДЗ) Объединение (совокупность). Расстояние больше заданного: значения $f(x)$ лежат за пределами отрезка $[-g(x); g(x)]$.

Примечание: Для уравнений и неравенств, содержащих сумму нескольких модулей (например, $|x-1| + |x+2| = 5$), применяется метод интервалов: числовая прямая разбивается корнями подмодульных выражений на знакопостоянные промежутки, и на каждом из них модули раскрываются строго по определению.

4. Модуль и Графики функций

Базовый график $y = |x|$ представляет собой биссектрисы первой и второй координатных четвертей («уголок» с вершиной в начале координат). При наложении модуля на произвольную функцию $f(x)$ происходят следующие геометрические преобразования:

Внешний модуль: $y = |f(x)|$

Значения функции становятся неотрицательными ($y \ge 0$).

Построение: Часть графика, лежащая выше оси $Ox$, сохраняется без изменений. Часть графика, лежащая ниже оси $Ox$, симметрично отражается наверх относительно оси $Ox$.

Внутренний модуль: $y = f(|x|)$

Функция становится четной: $f(|-x|) = f(|x|)$.

Построение: Часть графика в левой полуплоскости ($x < 0$) полностью стирается. Часть графика из правой полуплоскости ($x \ge 0$) сохраняется и симметрично копируется налево относительно оси $Oy$.

6. Практика

Задача: Уравнение вида $|f(x)| = g(x)$

Решите уравнение: $\quad |2x - 3| = x - 1$

💡 Подсказка: Воспользуйтесь второй строкой из таблицы равносильных переходов. Справа находится выражение с переменной. Запишите условие неотрицательности правой части ($x - 1 \ge 0$), а затем решите совокупность двух линейных уравнений: $2x-3 = x-1$ и $2x-3 = -(x-1)$.

Решение:

1. Перейдем к равносильной системе. Модуль не может равняться отрицательному числу, поэтому накладываем условие на правую часть:
$$\begin{cases} x - 1 \ge 0 \\ \left[\begin{gathered} 2x - 3 = x - 1 \\ 2x - 3 = -(x - 1) \end{gathered}\right. \end{cases} \quad \Leftrightarrow \quad \begin{cases} \mathbf{x \ge 1} \\ \left[\begin{gathered} 2x - x = 3 - 1 \\ 2x - 3 = -x + 1 \end{gathered}\right. \end{cases}$$

2. Решаем оба уравнения совокупности:
Первое уравнение: $x_1 = 2$.
Второе уравнение: $3x = 4 \implies x_2 = \frac{4}{3} = 1\frac{1}{3}$.

3. Проверяем выполнение условия $x \ge 1$:
Оба корня ($2$ и $1\frac{1}{3}$) больше единицы, следовательно, оба входят в ответ.

Ответ: $1\frac{1}{3}; \quad 2$
